## 项目

| 目录 | 问题 | 状态 |
|---|---|---|
| [`grignard-order-effect/`](grignard-order-effect/) | 同一批料、只改加料顺序，格氏反应产率为什么差 25–39 个百分点？能否从第一性原理算出 | 机制假设成立，未建立经验证的定量模型；量子化学层未收敛 |

## 约定

每个项目目录里：

- `paper/` — 短文与补充材料索引
- `README.md` — 项目说明、关键数字、限制
- 代码与计算脚本
- HTML 报告（自包含，可直接用浏览器打开）

出版商的 PDF 不随仓库分发。
