速率是怎么算的：实验、量子化学与产率模型如何接上

Barbier 一锅法 vs 预制格氏 · 2026-11-03

一句话

速率常数来自三个互不相同的来源：格氏生成速率取自文献实测； 加成与 MPV 的速率用量子化学（MACE-POLAR 机器学习势）算出势垒再换算； 镁表面积由几何估算。三者放进一个常微分方程网络，算出产率，再和实验对照。

二、量子化学到底算了什么

用的是 MACE-POLAR-1-M——一个在 OMol25 数据集（1 亿个 ωB97M-V 级别 DFT 结构）上训练的 极化机器学习势。它不是从头算 DFT，而是 DFT 的代理；在本次工作中它扮演"能算显式溶剂、 算得起几十个原子"的角色。

算了两个反应

（1）羰基加成：CH₃MgCl(THF) + 乙醛 → 醇盐。固定 C···C 距离，放开其余坐标做弛豫扫描， 取能量最高点。

加成路径上的四个瞬间。可以看到 C–C 在缩短，而 Mg–C 在最高点几乎没动—— 这正是后来发现"鞍点没验证成功"的地方。

（2）MPV 氢转移：CH₃O–MgCl + CH₃CHO → HCHO + CH₃CH₂O–MgCl。 固定 H···C(羰基) 距离做弛豫扫描，势垒 15.5 kcal/mol。

三、从势垒到速率常数

k = (kBT / h) × (1/C°) × exp( −ΔG‡ / RT )
指前因子 kBT/h ÷ C°（C° = 1 M）在 298 K 是 6.2×10¹² L mol⁻¹ s⁻¹。 难点在于 ΔG‡ 不等于 ΔE‡：量子化学算的是电子能，而速率需要自由能。 MPV 是双分子成环反应，要加一个熵校正 ΔS‡ ≈ −25 cal mol⁻¹ K⁻¹。

这一步是整个模型最脆弱的地方。熵校正是取的双分子成环的教科书值（−20 到 −30）， 不是测出来的。模型对它的取值很敏感：ΔS‡ 取 −20 时缺口是 −0.73，取 −25 时 −0.385， 取 −30 时 −0.33。

四、从速率到产率

反应网络（常微分方程）：
Mg + RX → RMgX 　　　　　　　　　 ks·(A/V)·θ 2 RMgX ⇌ R₂Mg + MgX₂ 　　　　　　 Schlenk 平衡 RMgX + S → P 　 / 　 R₂Mg + 2S → 2P 　 kG RMgX + RX → R–R 　　　　　　　　　 Wurtz 偶联 S + Mg → 还原产物 　　　　　　　　 表面还原 2 S + Mg → 频哪醇 　　　　　　　　 表面偶联 P + S → 还原产物 　　　　　　　　　 MPV（kMPV）
加料顺序不写成参数，而是写成进料时间表：预制法先加 RX、静置、再加 S； 一锅法两者同时在场。θ 是镁表面的自由位点分数，由 RX 和 S 竞争吸附决定。

六、量子化学在这里起到的作用，以及它的边界

起到的作用：它提供了两个实验上很难直接测量的速率常数—— 羰基加成的 kG 和 MPV 的 kMPV。没有这两个数，模型里就只有可调参数， 没有预测能力。它也验证了 Mg–C / Mg–Cl 这类化学在它的训练分布之内。
边界（必须说清楚）：
  • 势垒是单构象扫描，不是系综平均。没有多构象 Boltzmann 加权，没有分子动力学采样。
  • 加成路径的"最高点"经过 Dimer + 频率检验，结果是 0 个虚频，最低振动模只有 0.0–0.5 cm⁻¹ ——势垒顶部是一片近乎平坦的高原，数值上无法确认它是鞍点。
  • 同一体系在 r = 4.40 Å 处，两个构象相差 3.84 kcal/mol，比文献误差棒（±0.8）还大。 所以这些势垒值本身有未收敛的成分。
  • MPV 的熵校正是假设值，不是算出来的。
所以正确的说法是：量子化学在这里提供的是"量级正确、机制方向正确"的速率估计， 不是一个经过严格收敛的定量自由能。模型能解释条件依赖和大部分产率差， 但把它的数字当成精确值是不合适的。

七、要让它更硬，需要什么

  • 势垒做构象系综（多构象 + Boltzmann 平均，或机器学习势的分子动力学采样）
  • MPV 的熵校正用显式溶剂自由能方法复核
  • 实验上补两组数据：未反应醛的回收率、MPV 副产物 3/5 的定量
