MPV 通道的势垒：把最后一个自由参数钉住

MACE-POLAR-1-M · 气相单构象 · 弛豫扫描 · 2026-11-03 · 数据 mpv_barrier.json

这次在算什么

反应 CH₃O–MgCl + CH₃CHO → HCHO + CH₃CH₂O–MgCl（Meerwein–Ponndorf–Verley 的氢负转移）
模型 13 原子简化体系：Mg 同时连着 Cl、甲氧基 O、乙醛 O，形成六元环过渡态。
方法 MACE-POLAR-1-M，沿 H···C(羰基) 距离做弛豫扫描（每点放开其余坐标）。
目的 之前 kMPV 是自由参数，需要独立估计。

目标链条

  • 大目标同一批料换加料顺序，为什么产物分布不同
  • 中目标把差异归因到「产物醇盐与未反应醛共存」这条通道
  • 小目标把这条通道的速率常数从拟合值换成算出来的值
  • 本次算 MPV 势垒，与模型反推的 1×10⁻⁴ L mol⁻¹ s⁻¹ 对照

结果

氢从甲氧基碳迁移到羰基碳，势垒出现在 H···C ≈ 1.30 Å。越过 1.30 Å 后 H 已经完全转移 （C–H 从 1.30 拉到 2.19 Å），能量迅速回落。

换算

假设ΔG‡ / kcal mol⁻¹k / L mol⁻¹ s⁻¹
只用 ΔE‡，不计熵15.52.7×10¹
ΔS‡ = −20 cal mol⁻¹ K⁻¹21.51.2×10⁻³
ΔS‡ = −25 cal mol⁻¹ K⁻¹23.09.3×10⁻⁵
ΔS‡ = −30 cal mol⁻¹ K⁻¹24.47.5×10⁻⁶

判读

对上了：要重现模型反推的 kMPV = 1×10⁻⁴，需要 ΔG‡ = 22.9 kcal mol⁻¹， 即 ΔS‡ = −24.8 cal mol⁻¹ K⁻¹。而双分子成环过渡态的熵损失教科书值正是 −20 到 −30，取 −25 得到 9.3×10⁻⁵——差 7%。

但不能过度解读：−25 这个值是「让它对上」选的。真正独立的结论只有一条—— 这条反应是熵控的：电子势垒只有 15.5，但必须付约 7.5 kcal/mol 的熵代价， 否则 MPV 快 10⁵ 倍，连预制法都会被毁掉（模型里 pre/bar 双 0）。

可检验的推论：任何把两个反应物预组织到一起的环境（共吸附、螯合、限域） 都会大幅降低这笔熵代价，从而加速 MPV。
