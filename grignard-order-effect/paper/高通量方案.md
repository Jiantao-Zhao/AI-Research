## 一、对初版漏斗的批判性审视

**P1 验证顺序倒置**：蒸馏是偏差放大器，不是纠错器。初版把教师验证隐含推到 L2，而 L1 蒸馏发生在验证之前——若 MACE-POLAR 有 4.8 kcal/mol 系统偏差，L1 先把偏差固化进一个快 10–20 倍的模型，再污染全部 60 张自由能面。**验证必须是第 0 层，且是硬门槛。**

**P2 L0 复现已证伪的方法**：单构象气相扫描势垒已被证明是偶然相符（系综加权后偏 4.8）。用 GFN2-xTB 气相扫描做"势垒预筛"是把同一错误换个便宜模型再犯一遍。xTB 层只能出**热力学/结构描述符**，不能出动力学判据。

**P3 换算法 ≠ 换坐标**：窗口 3、4 漂移反转说明 1D C–C 距离不是好坐标。在同一个坏坐标上把伞形换成 well-tempered metadynamics，PMF 同样有偏，还多了逃逸到非物理态的风险。**坐标资格认证必须是独立步骤，先于任何批量生产。**

**P4 提速来源没想清**：实测瓶颈是长程静电求和（cuequivariance 无效即佐证），不是 SO(3) 卷积。短程学生照搬教师长程静电则速度不变；删掉则物理改变（THF 中 Mg²⁺ 的长程极化不是小项）。可行折中是"短程 MACE + 电荷头 + PME"——提速来源与保真风险在同一处，必须显式验证。

**P5 目标错位**：产率差 84% 来自供给受限转化、16% 来自 MPV，加料顺序主要通过**活性物种浓度**起作用。最高价值的量子目标是三个：加成 ΔG‡、Schlenk/聚集平衡（便宜、无 TS 搜索、直接进 ODE）、MPV 势垒（仅短名单）。另外"138 卡时串行不可行"混淆了墙钟与成本：Snellius 上 138 卡时 ≈ 2 节点日，本身可行；4 卡一窗并行只降墙钟不降卡时。真正约束是预算该花在哪些体系上。

## 二、修正后的工作流（V → C → T0–T3）

### V 层｜教师验证门槛（≈10 GPU·h 或 ~2500 核时）

- 输入：既有 MD 轨迹沿反应进程抽 300 帧，切 60–90 原子溶剂化簇。
- 基准：ωB97X-D/def2-TZVP-D3 单点，比对 MACE-POLAR 沿路径相对能。
- 判据：MAE ≤ 1.0 kcal/mol，势垒区最大偏差 ≤ 2.0。
- 第二锚点：显式溶剂 PMF 势垒（相对 1 M 标准态）经 TST 换算 k₂，与文献 Grignard 加成速率比对，容差 1 个数量级。
- **失败路径**：不达标 → 用同一批 DFT 标签增量微调（≤20 GPU·h）复验；仍不达标 → 放弃本体 PMF 高通量，降级为 DFT 簇 + 隐式溶剂热力学，缩到 ~10 体系。

### C 层｜反应坐标资格认证（≈30 GPU·h）

见第三节。**失败路径**：committor 偏离 0.5±0.15 或 MFEP 不稳定 → 加第三 CV（C=O 取向角）或降级为仅定性排序。

### T0｜热力学预筛（CPU ~500 核时，0 GPU）

GFN2-xTB/CREST 构象系综 + ALPB(THF)：Schlenk ΔG、单体–二聚–ate 平衡、R–MgX···羰基络合 ΔG、反应 ΔG；描述符：构象熵、%V_bur、羰基亲电指数。判据：剔除反应 ΔG>0 与 Schlenk 完全偏聚体系；按描述符空间多样性选 20 底物 × 3 卤化物。**不做势垒预筛。**

### T1｜学生模型（仅 V 通过后，≈15 GPU·h）

- 标签来自 4–5 个代表性底物 × 卤化物短 MD（各 30 ps ≈ 7.5 卡时，边跑边标）+ 既有轨迹，覆盖全 CV 区与离路构型。
- 架构：短程 MACE + 电荷头 + PME 长程。
- 验证：2 个**未参与训练**体系上 |ΔΔG‡| ≤ 0.5 kcal/mol。
- **失败路径**：放弃学生批量层，教师直跑 ~25 体系（~63 卡时，预算内，牺牲广度保深度）。

### T2｜批量生产（≈45 GPU·h）

- 学生跑 60 张路径 CV PMF（0.25 卡时/张 ≈ 15）。
- 教师全精度复核 8 个跨度体系（≈18）。
- 学生−教师差一致（σ<0.5）则作系统性修正带外推；不一致则教师比例升到 50%。
- MPV 势垒仅 10 个短名单（教师 4 + 学生 6）。

### T3｜代理 + 主动学习（≤5 GPU·h）

GP/集回归带不确定度，用途是**选哪些候选升级到教师层**，不做最终断言；60 个训练点太小，禁止外推出描述符空间。

### 闭环耦合

ΔG‡ + Schlenk 常数写入微动 ODE；A/V 改为在参考体系**转化曲线**（非产率）上拟合一次后冻结，消除循环论证；先做 ODE 对 ΔG‡±1/±2 的敏感性分析（本地零成本）定精度需求，再定 T2 教师复核比例。

## 三、反应坐标与采样设计

**诊断**：产物是镁醇盐（Mg–O 键），反应物是 O→Mg 配位络合物——Mg–O 接触贯穿全程。1D C–C 把它留成自由度，乙醛翻转正是在垂直方向吸收约束。

三步：

1. CV1 = d(C–C)、CV2 = d(Mg–O_醛)，4-walker well-tempered metadynamics 粗扫 2D 面（4×60 ps = 240 ps ≈ 12 卡时）。
2. 2D 面上 string / 最小自由能路径（本地 numpy，零成本）。
3. 沿 MFEP 定义路径 CV（s = 沿路进度，z = 离路距离），生产用 12–14 窗伞形（自适应 k：内 ≥20、中 5、外 2 eV/Å²，最内窗中心 ≥1.75 Å），12 窗 × 20 ps ≈ 12 卡时。

收敛判据 = 直方图重叠 + 分窗 PMF 拼接一致性。生产不用 WT-MetaD（收敛速率未知），MetaD 只用于探索，OPES 备选。

**committor 检验**：TS 区隔面射 60 条 1–1.5 ps 短轨迹（≈5 卡时），要求 p ≈ 0.5±0.15——同时修复"势垒来自约束扫描极大值、未经虚频/动力学验证"的缺陷（虚频 bug 第 1 周本地修复）。

## 四、最小验证集（3 体系、三层基准）

体系：① CH₃MgCl + 乙醛（参考系）② PhMgBr + 苯甲醛（换卤换底物，文献动力学最全）③ EtMgCl + 新戊醛（位阻压力测试）。

| 层 | 内容 | 成本 |
|---|---|---|
| (a) | 300 帧 DFT 单点沿 MFEP（①②各 150） | ≈10 GPU·h 或 ~2500 核时 |
| (b) | 文献 k₂ 锚点（①） | 0 |
| (c) | 条件性金标准：8 分子 THF 簇（~80 原子）CP2K DFT-MD 微型 PMF，4–8 窗 × 15 ps | ~1000–1500 核时，仅当 (a)(b) 模糊时启动 |

判定：过 (a)+(b) → 开闸 T1/T2；(a) 失败 → 微调复验；(c) 与 MACE 簇 PMF 差 >2 kcal → 教师降级为"仅趋势可信"，项目转向排序而非定量。

## 五、排期与预算（上限 200 GPU·h，超即止损）

- **第 1–2 周（≈55 卡时 + CPU）**：修虚频 bug；收割在跑 4 卡伞形作业做 2D 诊断；装 packmol 建新底物盒子；C 层 2D MetaD(12) + 路径 CV 伞形(12) + committor(5)；V 层 DFT 单点(10)；T0 预筛(500 核时)；ODE 敏感性（本地）。周末判 V/C 双门。
- **第 3–4 周（≈30 卡时）**：V 过 → T1 蒸馏 + 留出验证(15) + 教师 4 体系试点(9) + MPV 试点(3)；V 败 → 微调(≤20) + 复验，其余顺延。
- **第 2–3 月（≈60–70 卡时）**：T2 批量 60 PMF + 教师复核 8 + MPV 短名单；T3 代理与升级轮；微动闭环。产出：20×3 的 ΔG‡/Schlenk 表、参考对产率差预测区间、3 个留出底物的可实验检验预测。

**账目**：已用 2 + V 10 + C 30 + T1 15 + T2 45 + T3 5 = 107，重做/微调储备 90 → **≤197**。

**止损顺序**：砍 MPV 层 → 教师复核降到 4 体系 → 广度降到 12 底物。所有作业墙钟 ≤ 数小时，远低于 5 天时限。

## 六、诚实声明

**有把握**：坐标病理诊断与 2D→MFEP→路径 CV 工作流；验证先行的排序；全部成本算术（基于实测 20 ps/卡时）；各层失败路径。

**推测**：学生模型保真度（点电荷+PME 替代极化长程是最大物理风险）；GFN2-xTB 对有机镁共价化学的可靠性（Mg 参数化弱）；metadynamics 在该体系的收敛速率；簇切取 DFT 基准对集体溶剂效应的代表性。

**最可能失败**：教师过不了 V(a)（气相已偏 4.8，概率不低）且 300 帧微调不足以修复 → 降级为"教师只做短名单精确层 + xTB/簇热力学广度层，承认仅排序精度"。次可能：学生留出验证失败 → 教师直跑 25 体系。第三：C 层证明需 3D CV → 预算内只够参考系 + 短名单，广度自动缩水。
